# 🎸 SoundHub Studio — Music Studio Rental & Utility App

Aplikasi mobile berbasis **Flutter & Dart** untuk layanan penyewaan studio musik (**SoundHub Studio**) yang dilengkapi dengan fitur kalkulator estimasi biaya sewa dan pemantauan kondisi cuaca real-time untuk wilayah Bandung.

Proyek ini dikembangkan sebagai bagian dari mata kuliah **Pemrograman Mobile** di **Institut Teknologi Nasional (Itenas) Bandung**.

---

## ✨ Fitur Utama

- **Splash Screen & Dashboard Interaktif:** Navigasi utama menuju seluruh modul layanan studio musik.
- **Informasi Biodata & Kontak Studio:** Halaman profil pengembang serta informasi kontak dan lokasi studio.
- **Kalkulator Biaya Sewa:** Perhitungan estimasi tarif sewa studio dengan dukungan operasi multi-operator dan kalkulasi persentase/diskon.
- **Cuaca Real-Time (Open-Meteo API):** Integrasi REST API untuk menampilkan prakiraan cuaca terkini di area Bandung sebelum pengguna berangkat menuju studio.

---

## 🛠️ Teknologi yang Digunakan

- **Framework:** Flutter (SDK 3.50.0) & Dart
- **API Integration:** `http` package dengan **Open-Meteo Weather API**
- **Target Platform:** Android (SDK 36)
- **Tools:** Visual Studio Code / Antigravity IDE, Git & GitHub
